# 兼容性

这个项目只用公开的配置字段（`agent.*.permission`、`agent.*.disable`、
`default_agent`），没有插件、没有可执行代码，所以理论上桌面版和 TUI 都适用。
但「理论上适用」不等于「验证过」，下表只记录真实跑过的组合。

## 验证矩阵

| OpenCode 版本 | 平台 | 形态 | 结果 | 验证方式 |
| --- | --- | --- | --- | --- |
| Desktop 1.19.3 | Windows | 桌面版 | 已验证 | 作者实测（切换档位、确认权限行为、确认选择器显示） |
| Desktop 1.19.3 | Windows | TUI | 未验证 | — |
| Desktop 1.19.3 | macOS | 桌面版 | 未验证 | — |
| Desktop 1.19.3 | Linux | 桌面版 | 未验证 | — |
| 其他版本 | 任意 | 任意 | 未验证 | — |

CI（GitHub Actions）在 Ubuntu / macOS / Windows 三个 runner 上校验配置的语法与
schema，并跑一遍安装 → 重装 → 卸载的往返测试。**这验证的是文件与脚本的正确性，
不是 OpenCode 运行时行为**——真实行为只能在装了 OpenCode 的机器上验证。

## 已知的版本敏感点

| 项目 | 说明 |
| --- | --- |
| `permission` 字段 | 依赖 OpenCode 的公开配置 schema。若某个版本删改了字段名，配置会被忽略或报错。 |
| 自定义 agent 的 `question` 默认值 | 默认 `deny`。本仓库三个档位都显式写了 `question: allow`，不依赖这个默认值的行为是否变化。 |
| `agent.*.disable` | 用来隐藏内置的 `build` / `plan`。属于可选配置，去掉也能用。 |
| 快捷键 `Ctrl + .` | 桌面版默认绑定。被改过键位或输入法占用时会失效，见 [faq](faq.md)。 |

## 怎么自己验证

在一台装了 OpenCode 的机器上，按顺序走一遍：

1. **安装**：跑 `install.ps1` / `install.sh`，或手动复制 `agent/*.md`。
2. **重启**，打开 agent 选择器（桌面版 `Ctrl + .`），能看到三档。
3. **切到 `read-only`**：让它改一个文件。应该是工具不可用/被拒绝，而不是弹确认。
4. **切到 `auto-edit`**：让它改一个文件（应直接成功），再让它跑 `echo ok`（应弹确认）。
5. **切到 `full-auto`**：让它跑 `echo ok`，应直接执行。
6. **`question` 检查**：让它在需要澄清时提问，应该能弹出问题而不是自己瞎猜。
7. 卸载后重启，三档应从选择器消失。

## 回报结果

如果你在别的版本或平台上验证通过（或踩到坑），欢迎开 issue 并附上：

- OpenCode 版本号与安装形态（桌面版 / TUI）
- 操作系统与版本
- 上面 1–6 步中哪一步不符合预期

确认后会把对应行从「未验证」改成「已验证」。
